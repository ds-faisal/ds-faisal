### 🔬 Notable Research: The "Accuracy Paradox"
In my MS Thesis on cross-lingual NLP (LaBSE embeddings), I uncovered a critical flaw in naive ML evaluation: 
* Human-mediated semantic obfuscation yielded a **96% Accuracy rate** but a catastrophic **0.24 Recall**. 
* The model was tricked into high True-Negative states, completely missing the actual target data. 
* **Conclusion:** Standard accuracy is a vanity metric. High-stakes environments require robust evaluation (MCC, F2-Score) and Causal Inference to model true cause-and-effect interventions.
